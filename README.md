# 🗓️ 마이스터 캘린더

마이스터고 학생을 위한 시험·학사일정 캘린더 PWA입니다.
컴활·기능사·한국사·KBS한국어·토익·오픽 같은 자격시험 일정과 학교 학사일정, 개인 목표와 D-day 알림을 한 화면에서 관리합니다.

**배포 주소 → https://meister-calendar.pages.dev/**

휴대폰 브라우저로 열고 "홈 화면에 추가"하면 앱처럼 전체화면으로 실행되고, 오프라인에서도 열립니다.

---

## 화면 구성

하단 탭 5개로 나뉩니다.

| 탭 | 하는 일 |
|---|---|
| 📅 **캘린더** | 월 단위 달력. 날짜를 누르면 그날 일정이 뜨고, 카테고리 칩으로 시험 종류별 필터링. 아래에 다가오는 일정을 D-day와 함께 표시 |
| 🎯 **목표** | 목표와 마감일 등록. 체크로 완료 처리하고, 마감일은 달력에도 함께 표시됨 |
| 🏫 **학교** | 학교 이름을 검색해 등록하면 NEIS에서 학사일정을 가져와 달력에 합쳐줌 |
| 💼 **기업검색** | 취업 희망 기업 목록 검색. 초성 검색 지원(`ㅅㅅ` → 삼성전자), 카테고리 필터 |
| ⚙️ **설정** | D-day 알림 on/off, 알림 받을 시점(며칠 전) 선택, 시험별 공식 출처 바로가기, 앱 설치 버튼 |

## 주요 기능

- **D-day 알림** — 브라우저 알림 권한을 받아 지정한 며칠 전에 알려줍니다. 1분마다, 그리고 앱으로 돌아올 때마다 확인하며 같은 알림이 중복으로 뜨지 않게 태그로 막습니다.
- **NEIS 학사일정 연동** — 학교를 한 번 등록해두면 학교 일정이 자동으로 달력에 들어옵니다.
- **초성 검색** — 기업검색 탭에서 초성만 입력해도 매칭됩니다. 공백은 무시합니다.
- **오프라인 동작** — 서비스 워커가 정적 파일을 캐시하므로 네트워크 없이도 열립니다.
- **로컬 저장** — 목표·내 일정·학교 설정·알림 설정은 전부 `localStorage`에 저장됩니다. 서버에 계정도 데이터도 없습니다. 브라우저 데이터를 지우면 함께 사라집니다.

## 파일 구조

```
index.html        # 화면 전체 (마크업 + 스타일)
app.js            # 달력·목표·알림·학교 연동·기업검색 로직
data.js           # 시험 일정(EXAMS), 기업 목록(JOBS), 출처(SOURCES), 카테고리 정의
manifest.json     # PWA 매니페스트
sw.js             # 서비스 워커 (오프라인 캐시)
icon-192.png
icon-512.png
worker/
  neis-proxy.js   # NEIS 오픈API 프록시 (Cloudflare Worker)
  wrangler.jsonc
```

빌드 도구도 의존성도 없습니다. 파일을 그대로 서빙하면 됩니다.

## 로컬 실행

`file://`로 열면 서비스 워커가 등록되지 않으므로 정적 서버로 띄웁니다.

```
npx serve .
```

## 배포

**프론트엔드 — Cloudflare Pages**
빌드 명령 없이 저장소 루트를 그대로 배포합니다.

**NEIS 프록시 — Cloudflare Workers**

```
cd worker
npx wrangler secret put NEIS_KEY   # NEIS 오픈API 인증키
npx wrangler deploy
```

NEIS 인증키는 저장소에 두지 않고 Worker 시크릿으로만 관리합니다.
프록시는 허용된 엔드포인트(`/schoolInfo`, `/SchoolSchedule`, 급식·시간표)만 통과시키고,
클라이언트가 `KEY` 파라미터를 보내도 무시한 뒤 서버 쪽 키로 덮어씁니다.

배포한 Worker 주소가 바뀌면 `app.js` 상단의 `NEIS_PROXY` 상수를 함께 고쳐야 합니다.

## 데이터 갱신

일정과 기업 목록은 모두 `data.js`에 하드코딩되어 있습니다. DB가 없으므로 여기만 고치면 됩니다.

- 시험 일정 — `EXAMS` 배열. `{cat, date, title}` 형태이고 `date`는 `YYYY-MM-DD`.
  `cat`은 `comp`(컴활) / `gisa`(기능사) / `hist`(한국사) / `kor`(KBS한국어) / `toeic` / `opic` 중 하나.
- 기업 목록 — `JOBS` 배열.
- 출처 링크 — `SOURCES` 객체. 설정 탭의 "바로가기" 버튼이 여기를 씁니다.
